# RUNBOOK: порядок действий на тесте

Предусловия (до выдачи глав): ветка заморожена тегом `freeze-v1`; `make check` зелёный; ключи моделей и озвучки есть в окружении (ключ ElevenLabs вводится через защищённую форму, в файлы не писать). После тега код, промпты и доменный пакет не менять. Всё, что сломалось на тесте, фиксировать как есть и записывать в журнал, не чинить втихую.

## 1. Принять главы
Положить файлы каждой главы в `chapters/<имя>/` (md с маркерами `<!-- page N -->` и PDF/сканы). Главы не публиковать и никуда не выкладывать. Отметить время получения: `date -u`.

## 2. Три двойника: слой, маршрутизация, курс
```bash
JOBS=8 make course CHAPTER=<имя1>
JOBS=8 make course CHAPTER=<имя2>
JOBS=8 make course CHAPTER=<имя3>
make check
```
Главы можно гнать параллельно, но лимит запросов API конечный: если общий лимит на аккаунт, лучше по очереди (одна глава ≈ 10–20 минут при JOBS=8). Результат: `build/<имя>/org/layer.json`, `org/routing.json`, `org/coverage.json` (слой, маршрутизация, покрытие в формате организаторов), `out/<имя>/index.html` (курс). Если стадия упала (лимит, сбой процесса), просто повторить ту же команду: готовые разделы пропускаются.
Любую ручную правку результата записать: `tools/edit-log add <имя> <минуты> "что и почему"` (цель ≤30 минут на главу).

## 3. Ролики (назначенные узлы и сдвиг)
Для каждого узла, назначенного организаторами: `make video CHAPTER=<имя> NODE=<id узла>` (docs/video.md). Паспорт: `passports/<id>/passport.json`, готовый ролик: `out/video/`. Проверить автоматические проверки дорожки (WER, громкость, рассинхрон) в отчёте команды.

## 4. Модуль проверки на пакете закладок
Положить пакет (package.json, глава, кадры) рядом, затем `make review PACKAGE=<путь к package.json>`. Ответ `ответ.json` по схеме организаторов; проверить валидатором схемы. Ключ пакета (если выдан) не открывать до прогона.

## 5. Сдвиг домена
Следовать PLAYBOOK.md: новый доменный пакет (`domain-pack/<домен>/`), записать минуты сборки, затем `make course CHAPTER=<имя>` для главы нового домена; отчёт о покрытии шаблонами сцен: docs/video.md.

## 6. Сдача
`python3 -I tools/summary_metrics.py` (метрики и стоимость), `metrics/manual_edits.csv` (журнал правок с минутами; должен совпасть с историей коммитов), `MANIFEST.md`, список артефактов по главам. Коммит и push результатов в рабочую ветку; репозиторий публичным не делать.
