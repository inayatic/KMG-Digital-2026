## Блок B

### B5 / s07 #1: 43 МГц, стр. 52-53
- Ответ: относится к ДК1-713.
- Доказательство: стр. 52 внизу: «Аппаратура ДК1-713 измеряет sinΔφ/2, отношение вертикальных составляющих». Стр. 53, 1-я строка: «амплитуд |hz1|/|hz2| и величину (|hz1|-|hz2|)/|hz2| при частоте поля 43 МГц. Все три измеряемые величины зависят от». - Уверенность: высокая (скан 200 dpi).
- Рекомендация: lat.s07.06 (nuances) было «нельзя исключить, что относится ко всей аппаратуре» -> «43 МГц указана для ДК1-713 (стр. 53); для АДК-1 частота не названа». Не писать «ВДМ работает на 43 МГц».

### B6 / s08 #3: «ат» в задаче 57
- Ответ: в книге «ат» без расшифровки; единицу в МПа книга не даёт.

### B6 / s08 #4: температура 18 °C для рис. 41

### B7 / s09 #2: «потенциал у границы не равен ΔE»
- Ответ: частично; книга даёт ΔE/2 только при условии близкого к однородному по сопротивлению разреза.
- Доказательство: стр. 60, § 10: «Когда среда по сопротивлению близка к однородной, точки кривой СП, соответствующие границам пластов, определяются амплитудой = ΔE/2». Для неоднородной среды значение у границы автор числом не даёт (стр. 60-62, ΔU_СП < ΔE, υ).
- Уверенность: высокая.
- Рекомендация: lat.s09.01, поле data_implication: «значение потенциала у границы не равно статической амплитуде» -> «в среде, близкой к однородной по сопротивлению, у границы потенциал ≈ ΔE/2 (стр. 60); без этого условия значение книга не даёт». Оставить пометку «автор» только для ΔE/2.

### B8 / s10 #1: α_СП, ρв = const или ρп = const
- Ответ: ρв = const (сопротивление пластовой воды).
- Доказательство: стр. 62: «для повышения точности в разрезах, где ρв = const, часто используют относительную амплитуду αСП = ΔE/ΔEОП = [-kСПlg(ρф/ρв)]...». Индекс читается как «в»; согласуется с формулой (33), где ρв стоит в lg.
- Уверенность: высокая.
- Рекомендация: lat.s10.06 оставить «постоянным ρв (сопротивлением пластовой воды)» (уже так); ocr_note не нужен.
