### B2. s02 стр. 18 (часть s17 не моя)
Скан p18, кроп 260 dpi.
- Pн в (12): ответ да, параметр насыщения. Уверенность высокая. Стр. 15 («Величину Pн называют параметром насыщения»; Pн = ρнп/ρвп); на стр. 18 (12) ρпп/ρнп = Pнпп/Pн·ρф/ρв, и далее «водонасыщенные (kв = 100 %, Pн = 1)». Pп (пористости) тут не участвует.
- Индексы в «(kк/kннп)²»: на скане читается (kв/kвпп)², где kв = коэффициент водонасыщенности. Уверенность средняя (мелкий индекс). Согласуется с Pн = aн/kв^n при n = 2: Pнпп/Pн = (kв/kвпп)².
- Расшифровка индексов: ответ да (по тексту стр. 18): ρп = ρнп в продуктивном, ρп = ρвп в водонасыщенном; ρнп = нефтегазонасыщенная неизменённая часть, ρвп = водоносный пласт, ρпп = промытая зона. Высокая.
- Понижающее: «ρпп < ρнп при Pнпп/Pн « 1 и ρф ≥ ρв».
- Повышающее «ρф » ρв» относительно (12): по (12) ρпп/ρнп = (Pнпп/Pн)·(ρф/ρв), условие «ρф ≫ ρв» с Pнпп/Pн > 1 логично (произведение > 1). Противоречия нет. Высокая.
- Нейтральное «при пресных»: на скане «Pнпп/Pн·ρф/ρр = 1» (в знаменателе ρр, не ρв; вероятно опечатка автора). Связь «часто при пресных растворах» книга утверждает, но не доказывает. Средняя.
- Автор пишет для повышающего «(kв/kвпп)² < ρв/ρф». По (12) при Pнпп/Pн = (kв/kвпп)² получается ρпп > ρнп ⇔ (kв/kвпп)² > ρв/ρф. Знак у автора, по моему расчёту, обратный (вывод по арифметике, не по книге). Средняя.
- Рекомендация: узлы s02 про типы проникновения (lat.s02.04): оставить словесные формулировки без символов, повышающее/нейтральное с индексами и неравенством не закреплять; пометка ocr_note «неравенство (kв/kвпп)² < ρв/ρф у автора по (12) выглядит с обратным знаком, не использовать». Для заданий и роликов: «не подтверждено».
- В п091-05 (s17): не моя часть, не решал.
