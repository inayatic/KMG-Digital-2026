# Глава → курс (KMG-Digital-2026)

Конвейер превращает главу книги в учебный слой (граф узлов: утверждения, цитаты, страницы), выбирает форматы подачи, собирает курс (текст, задания, карточки) и ролики. Источник правды только книга. Репозиторий приватный: главы нельзя публиковать и отправлять во внешние сервисы, кроме модели (см. [MANIFEST.md](MANIFEST.md)).

## Что нужно
Linux, `python3` (3.10+) с `jsonschema`, `make`, `poppler-utils` (pdftotext, pdftoppm), Claude Code CLI (`claude`, авторизованный), для роликов `ffmpeg` и Chromium с Playwright. Проверка: `make check`.
Переменные: `DOMAIN` (папка доменного пакета в `domain-pack/`, по умолчанию `geology`), `LLM_MODEL` (модель для `claude -p`, по умолчанию как в CLI), `JOBS` (число параллельных вызовов, по умолчанию 4; для большой главы `JOBS=8`), `FORCE=1` (пересчитать готовые разделы), `TASKS_V=1` (задания старого типа вместо v2).

## Запуск
```bash
cp <файлы главы> chapters/<имя>/        # <имя>.md (с маркерами <!-- page N -->) и PDF/сканы
JOBS=8 make course CHAPTER=<имя>        # результат: out/<имя>/index.html (оглавление), out/<имя>/<раздел>/index.html
```
Повторный запуск пересобирает только недостающее: стадии пропускают разделы с готовым результатом, `make` смотрит на файлы `build/<имя>/`. Чтобы пересчитать с нуля: `rm -rf build/<имя> out/<имя>` (или `FORCE=1`).

## Стадии (`make course` выполняет их по порядку)
| Стадия | Что делает | Команда / скрипт | LLM |
|---|---|---|---|
| clean_ref | чистый эталон: текст страниц, OCR-мусор заменяется текстом PDF | `tools/clean_ref.py` | нет |
| units | абзацы, заголовки, формулы, таблицы, подписи как единицы `pNNN-NN` | `tools/make_units.py` | нет |
| nodes | нарезка на разделы, агент `layer-extractor` извлекает узлы с цитатами по разделу, ремонт покрытия, слияние | `stage.py nodes` (`split_sections`, `check_cov`, `merge_layer`) | да |
| verify | агент `verifier` ищет ошибки смысла, `layer-extractor` исправляет (один круг) | `stage.py verify` | да |
| org | слой в формате организаторов, enrich (тип трудности, термины, оценки видеоёмкости), патчи, проверка схем и цитат | `stage.py org` (`to_organizer_schema`, `apply_patches`, `check_org`) | да |
| course | агент `course-builder` пишет задания по разделам, сборщик проверяет их по утверждениям слоя и строит сайт | `stage.py course` (`build_course_all`) | да |

Ролики: `make video CHAPTER=<имя> NODE=<id узла>` (описано в docs/video.md). Модуль проверки внешнего пакета: `make review PACKAGE=<package.json>` (см. RUNBOOK.md).
Один раздел или стадию можно запустить отдельно: `python3 tools/stage.py <nodes|verify|org|course> <имя>`. Сухой прогон без LLM: `make course CHAPTER=<имя> STAGE_CMD=echo`.

## Проверки без LLM (секунды)
`make check` проверяет окружение, синтаксис `tools/*.py`, схемы организаторов и для каждой собранной главы `check_cov` (покрытие, целостность) и `check_org` (схемы, цитаты на своей странице в исходном md, битые связи). `make check CHAPTER=<имя>` для одной главы.

## Ручные правки и метрики
Любая правка результата после сырого прогона записывается: `tools/edit-log add <имя> <минуты> "что"` (или `start`/`stop`), файл `metrics/manual_edits.csv` в формате организаторов. Токены и деньги стадий дописывает `tools/stage.py` в `metrics/metrics.csv`; сводка: `python3 -I tools/summary_metrics.py` → `metrics/summary.md` (оценка стоимости, не счёт).

## Структура
`chapters/` исходные главы; `build/<имя>/` промежуточные и итоговые данные (units, nodes, org/layer.json, org/routing.json, course/); `out/<имя>/` курс; `passports/` паспорта роликов; `domain-pack/geology/` доменный пакет (глоссарий, заблуждения, чек-лист физики, стайлгайд, ударения); `tools/` стадии и проверки; `tools/prompts/` промпты стадий; `.claude/agents/` агенты; `reference/organizers/` материалы организаторов (схемы, модуль проверки). Плейбук для нового домена: [PLAYBOOK.md](PLAYBOOK.md). Порядок действий на тесте: [RUNBOOK.md](RUNBOOK.md).

## Ограничения (честно)
Агенты в основном сверяют текст и `clean.md`, сканы открывают выборочно: числа, индексы и знаки в OCR-искажённых местах не гарантированы. Рисунки книги в курс не включаются. Физика заданий и роликов не подтверждена ментором (его нет): непроверенное помечено «не подтверждено». Стоимость и время зависят от размера главы (Барабошкин, 155 стр.: около $7 за слой, проверку, enrich и курс; цифры в `metrics/summary.md`).
