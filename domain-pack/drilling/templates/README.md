# Шаблоны сцен домена «бурение» по типам трудности

Оценка по каталогу `tools/video/views.md` и коду `tools/video/scene.js`; ролик по шаблонам, которые «нужны новые», не рендерился. Тип трудности взят по определениям организаторов (reference/organizers/06_подача_и_референсы).

| Тип | Что показать в бурении (глава про проявления) | Шаблон | Без изменений? | Что подставить / чего не хватает |
|---|---|---|---|---|
| М механизм | приток пластового флюида в скважину: давление в стволе ниже пластового → поступление → рост объёма в приёмной ёмкости | `column` (колонна скважины) + `compare` (до → после) | частично | `column` рисует разрез скважины; приток стрелкой нужно задать `params`; полноценная «скважина с притоком» — новый шаблон |
| М механизм | рост уровня в приёмной ёмкости как признак | `xy_plot` (V(t) по точкам) + `conclusion` | да | точки V(t) в `params.points`, подписать оси и единицы (м³) |
| Пр процедура | порядок действий при проявлении: остановить циркуляцию, закрыть превентор, контролировать давление | `chips` (шаги), `conclusion` | да | шаги из слоя; числа порогов только «по книге, стр. N» |
| Н неопределённость и решение | порог 10 %/1 м³ и риск ложного/пропущенного проявления | `compare`, `log_bar` | частично | `log_bar` по умолчанию в «Ом·м»: обязательно задать `params.unit` |
| И косвенное измерение | признак проявления виден по косвенным данным (объём в ёмкости, расход, давление), а не по самому флюиду | `compare`, `xy_plot` | да | подписать «косвенно»; значения из слоя |
| Ф формализм | формулы расчёта давлений и объёмов из главы (4.1)–(4.2) | `xy_plot`, `conclusion` | да, если индексы формул подтверждены по скану | формулы с OCR-искажёнными индексами не использовать |
| В время | динамика роста объёма во времени | — | нет | нужен новый шаблон: временной ряд с отметкой момента обнаружения |
| П пространство | скважина и пласт в разрезе, глубина вниз | `column`, `flood_section` | частично | `flood_section` для геологического разреза; для бурового разреза нужна своя раскладка |
| Р распознавание | распознать признак проявления на кривой/диаграмме станции | — | нет | нужен новый: имитация записи уровня и расхода во времени (по данным слоя, метка «симуляция») |

Итог: из 9 строк без изменений подходят 4, частично 3, новых шаблонов нужно 3 (скважина с притоком, временной ряд с отметкой, имитация записи). Основа сцен (`title_card`, `chips`, `compare`, `conclusion`, `xy_plot`, `log_bar`) домен-независима.
