# Шаблоны сцен домена «фильтрация» по типам трудности

Шаблоны рисует движок `tools/video/scene.js` (каталог `tools/video/views.md`); здесь — какой шаблон берётся для какого типа трудности в этом домене и что подставляется в `params`. Код шаблонов не менялся. Оценка «подходит без изменений» сделана по коду и каталогу шаблонов, ролик в этом домене НЕ рендерился.

| Тип | Что показать в фильтрации | Шаблон | Без изменений? | Что подставить / чего не хватает |
|---|---|---|---|---|
| М механизм | жидкость течёт по порам от высокого давления к низкому; скорость фильтрации ≠ скорость частиц | `rock_grid` + модель `resistor_grid_2d` | частично | Математика та же: стационарное div(σ∇φ)=0 ⇔ div((k/μ)∇p)=0 (несжимаемая жидкость, закон Дарси); φ → p, σ → k/μ, ток → расход. Но подписи «ρв = … усл.», «R = … отн.», «кварц/кальцит», «+/−» зашиты в коде (docs/team/issues.md, п. 4) |
| М механизм | перенос/вытеснение | `compare`, `conclusion` | да | схема «до → после» словами |
| Ф формализм | закон Дарси: Q пропорционален Δp, k, площади; обратно μ и длине | `xy_plot` (точки Q(Δp) из `params.points`), `conclusion` | да | точки из таблиц/формул главы; нелинейный участок (пределы применимости) — вторая серия точек: шаблон рисует одну серию, нужна правка или два кадра |
| Ф формализм | диапазоны проницаемости (дарси, мД) | `log_bar` | да | `params.unit` = «мД» (по умолчанию «Ом·м» — обязательно задать) |
| И косвенное измерение | проницаемость не измеряется в пласте напрямую: из расхода и перепада давления | `compare` (наблюдение → вывод) | да | |
| В время | упругий режим: возмущение давления распространяется не мгновенно | — | нет | нужен новый: профиль p(r, t) по времени (модель пьезопроводности) |
| П пространство | плоскорадиальный приток к скважине, воронка давления | `split` (план + разрез), `xy_plot` (p(r)) | частично | плана с изобарами нет: нужен новый `pressure_map` |
| Пр процедура | порядок расчёта (схема → уравнение → граничные условия) | `chips`, `conclusion`, `title_card` | да | |
| Н неопределённость | k по керну vs по испытанию; масштаб усреднения | `log_bar` (диапазон), `compare` | да | |
| Р распознавание | режим течения по графику Q(Δp) (линейный/нелинейный) | `xy_plot` | да | |
| любой | крючок, вывод | `title_card`, `chips` | да | |

Не подходят домену (геологические по смыслу): `plan_bend`, `flood_section` (подписи «русло/пойма» зашиты), `column` (стратиграфическая колонка), `ion_surface` (подписи по умолчанию переопределяются, но сюжет двойного слоя не из этого домена).

Итого: без изменений подходят 7 из 11 шаблонов (`title_card`, `chips`, `log_bar` с `unit`, `compare`, `xy_plot`, `conclusion`, `split`); `rock_grid` подходит по модели, но не по подписям; 3 не по домену; нужны новые: `pressure_map`, профиль давления во времени.
