# Доменный пакет: фильтрация (подземная гидромеханика)

Второй домен для проверки «сдвига домена» (reference/organizers/05_шаблоны/domain_pack_template.md): структура та же, что у `domain-pack/geology/`, код не менялся. Источники: Басниев, «Нефтегазовая гидромеханика», стр. PDF 353–380 (`build/basniev/clean.md`); Баренблатт и др., гл. I, стр. PDF 5–19 (`build/barenblatt_gl1/clean.md`). Запуск с пакетом: `DOMAIN=filtration make course CHAPTER=<гл>`.

| `misconceptions.json` | 23 заблуждения `misc.filt.*` (9 core, 14 reference) | 22 «книга», 1 «вне_книги»; 23 цитаты проверены скриптом |
