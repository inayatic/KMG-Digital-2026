# Глоссарий RU/EN (ГИС, петрофизика, гидромеханика пласта)

Правила: определение дано по книге, стр. = номер PDF-страницы (маркер). Столбец «Сов.→Запад» целиком `[вне книги, из общих знаний, проверить у ментора]`: книги этих эквивалентов не дают. Сокращения: Лат = Латышова (build/latyshova/clean.md), Бас = Басниев, Куз = Кузнецов, Вен = Вендельштейн, Бар = Баренблатт. В Лат часть индексов при OCR искажена (ρпп/ρвп/ρнп путаются), такие места помечены «сверить по скану».
