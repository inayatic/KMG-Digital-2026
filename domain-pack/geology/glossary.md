# Глоссарий RU/EN, домен geology (петрофизика, ГИС, подземная гидромеханика)

Источники терминов: черновик domain-pack/glossary.md (92 строки таблицы), термины слоя build/latyshova/nodes.json и организационного слоя build/latyshova/org/layer.json (поля terms_introduced / terms_used). Отдельного файла глоссария организаторов в reference/organizers/04_доменные_заготовки/ нет (там README, заблуждения, чек-лист, портреты, словарь ударений), поэтому «глоссарием организаторов» считается org-слой.

Правила чтения таблицы.
- Определения даны по книге; «книга, стр.» — номер PDF-страницы (маркер page в build/<книга>/clean.md). Лат = Латышова, Куз = Кузнецов, Бас = Басниев, Вен = Вендельштейн, Бар = Баренблатт.
- Колонка EN: английские эквиваленты книги не дают; все помечены «[вне книги, проверить у ментора]» и фактом не являются. Столбец «Сов.→Запад» черновика не перенесён (он целиком вне книги).
- Статус: К = ключевая цитата найдена дословно в clean.md на указанной странице (проверено скриптом); С = индексы, формулы и числа сверены по скану PDF (pdftoppm); «слой» = термин взят из слоя Латышовой, определение берётся из текста книги на странице. «исправлено» = в черновике было неверно.
- Индексы Латышовой: в OCR clean.md они путаются (ρпп читается как ρm/ρпх, ρнп/ρвп/ρп как ρин и т.п.). Верные чтения по скану: ρзп — зона проникновения; ρпп — промытый пласт (промытая зона); ρнп — нефтегазоносная порода/нефтенасыщенный пласт; ρвп — водонасыщенный пласт (обозначения автора, расшифровка вопрос ментору); ρф — фильтрат; ρв — пластовая вода; ρр — раствор; ρгк — глинистая корка; ρвф — смесь фильтрата с водой в промежуточной зоне (с. 17).
- Описания рисунков и блоки KEYWORDS в clean.md составлены моделью конвейера, а не книгой; как источник определений не использовались.
