# Доменный пакет: геология (ГИС, петрофизика, гидромеханика пласта)

Структура по шаблону организаторов (reference/organizers/05_шаблоны/domain_pack_template.md). Движок знает только пути; всё предметное лежит здесь. Для другого домена (например, бурения) собирается соседняя папка `domain-pack/<домен>/` с теми же файлами, код не меняется. Задание-образец для сборки: tools/prompts/domain_pack.md.

## Что важно знать
- Источник правды — книга. Всё, чего нет в книге, помечено «вне книги» / `status: вне_книги`; в курсы и ролики такое как факт не пускать.
- Расшифровки индексов ρнп, ρвп (и часть аббревиатур: ГК, НГК, ННК, КС, МКЗ, ГНК, ГВК, РНО, РВО …) в книге не даны. Помечены «вопрос ментору».
- Пакет собран только по слою Латышовой; для остальных глав (Басниев, Кузнецов, Баренблатт, Вендельштейн) покрытие выборочное (пункты 12–26 черновика чек-листа не перенесены).
- Чтобы пересоздать лист опечаток: `python3 -I tools/make_errata.py latyshova geology`.
