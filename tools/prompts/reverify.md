# Промпт стадии «reverify» (verifier), повторная проверка сегмента после правок
Подставляется: CHAPTER, KEY. Выполни tools/prompts/verify.md с CHAPTER, KEY (рабочая папка /tmp/claude-0/vwork2-KEY/) со следующими отличиями.

1. Выход: build/CHAPTER/sections/KEY/verify-r2.md и ask-mentor-r2.md. verify.md, ask-mentor.md, fixes.md и nodes.json НЕ меняй. Id замечаний V-KEY-R2-NNN.
2. Прочитай verify.md (замечания 1-го круга) и fixes.md (что исправлено). По каждому V-id проверь по книге и скану, что правка верна и не внесла новой ошибки. Статус: ок / исправлено неверно / не исправлено.
3. Отдельно ищи НОВЫЕ ошибки, внесённые правками (изменённые claims, ocr_note, пометки author, числа, индексы, знаки), и то, что 1-й круг пропустил. Скан открывай для каждой правки, где менялось число, индекс или знак; правки 1-го круга часто делались без скана.
4. Проверь, что id claims внутри узла уникальны, а пометки author/field_authors согласованы с текстом.
5. Не повторяй замечания 1-го круга, которые уже исправлены верно. Не придумывай ошибок: нет страницы, не выноси.
Отчёт ≤8 строк: статусы правок, новые замечания по тяжести, что не проверено.
