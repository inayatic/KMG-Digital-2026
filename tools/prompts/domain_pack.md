# Промпт стадии «domain_pack»: сборка файла доменного пакета (общие правила)
Подставляется: ЗАДАНИЕ (одно из: misconceptions, physics_checklist, glossary_bridges, pronunciation) и DOMAIN (geology).
Структура пакета (шаблон организаторов reference/organizers/05_шаблоны/domain_pack_template.md): domain-pack/DOMAIN/{glossary.md, misconceptions.json, physics_checklist.json, it_bridges.md, styleguide.json, pronunciation.md, stress_dictionary.md, errata/, templates/}. Движок знает только пути; всё предметное лежит в пакете.

Общие правила:
1. Источник правды: книги (chapters/<глава>/*.pdf, build/<глава>/clean.md; номера страниц = PDF-страницы) и учебный слой build/latyshova/nodes.json (поля узлов: misconception, layers, claims, it_analogy, external_prereqs). Знания модели из общих знаний не источник. Всё, чего нет в книге, помечай явно: status="вне_книги" (в json) или «[вне книги, проверить у ментора]» (в md). Не придумывай страницы.
2. Заготовки организаторов (reference/organizers/04_доменные_заготовки/, 03_стайлгайд/) сохраняй БЕЗ изменения id и формулировок; свои добавления отмечай полем source/status, чтобы было видно, что из заготовки, что из книги, что вне книги.
3. Черновик первого прохода лежит в domain-pack/*.md (плоские файлы glossary.md, misconceptions.md, physics-checklist.md, it-bridges.md). Он НЕ сверен по сканам. Перенеси из него то, что подтверждается книгой, страницу проверь по clean.md (ключевую цитату найди дословно); неподтверждённое оставь с status="вне_книги" либо в «вопросы ментору».
4. Для каждой страницы-ссылки из книги: открывай clean.md или скан (pdftoppm -f N -l N -r 130 -png <pdf> /tmp/claude-0/dp-ЗАДАНИЕ/p). Числа, индексы, знаки читай по скану, не по OCR.
5. Не пиши в чужие файлы: только в свои выходные файлы ниже. Рабочие файлы только в /tmp/claude-0/dp-ЗАДАНИЕ/. Не удаляй и не меняй черновики domain-pack/*.md и заготовки организаторов.
6. Язык русский. Без личных имён в файлах.
7. В конце выходного файла блок «Вопросы ментору» (то, что книги не подтвердили). Отчёт ≤8 строк: сколько пунктов из заготовки / из книги / вне книги, что не проверено.
