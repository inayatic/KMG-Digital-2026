# Прогон verifier на внешнем пакете (контрольный пакет организаторов)
Следуй .claude/agents/verifier.md. Пакет: reference/organizers/02_модуль_проверки/контрольный_пакет/package.json (схема review_package.schema.json), глава: тот же каталог, vendelshtein_gl1.md (номера страниц = метки `<!-- page N -->`). Формат ответа: reference/organizers/02_модуль_проверки/review_output.schema.json (категории и README.md рядом).
СТРОГО: не открывай, не читай и не ищи файл key.json и ничего, что на него ссылается (score_review.py тоже не запускай). Источник правды только текст главы; своих знаний о геофизике для вынесения замечания недостаточно, нужна страница главы.
Задача: для каждой цели из твоего среза решить, есть ли в ней заложенная ошибка относительно главы (около 1/5 целей заражено; встречаются верные, но неожиданно звучащие элементы: замечание к ним = ложная тревога, штраф). Для каждого элемента найди в главе страницу и сверь смысл: переворот знака, сверхобобщение, потеря условия/оговорки, измеренное vs выведенное, неверный масштаб/зависимость, неверный механизм, устаревшее как текущее, аналогия без границы или с неверной границей (A…), ошибки кадров/сцен (F…, S…, L…).
Одна ошибка = одно замечание на ту цель, где она сформулирована. page_pdf = страница главы, подтверждающая исправление; fix = исправленная формулировка; quote = дословная цитата с этой страницы. Не придумывай: нет опоры в тексте главы — не выноси.
Выход: JSON-файл {"package_id": "ctrl_vendelshtein", "remarks": [...]} по review_output.schema.json в путь, указанный ниже, плюс рядом файл *-notes.md: по каждой цели из среза — «ок»/«замечание» и одна строка почему (чтобы оценить ложные тревоги и пропуски). Рабочие файлы только в своём каталоге /tmp/claude-0/rwork-<срез>/. Отчёт ≤6 строк.
