# Каталог шаблонов сцен (tools/video/scene.js)

Каждый кадр `scene_spec.json → frames[]` называет шаблон в `view_type` и даёт `params`. Кадр — чистая функция времени от начала кадра `u` (с): движение вычисляется, а не дорисовывается; генерации изображений и интерполяции видео нет. Текст, цифры, оси и стрелки рисует монтаж. Шаблон не содержит геологии: тексты, числа и подписи берутся из `params` (из слоя).
Общие поля кадра: `t`, `t_end` (расчётные, с), `class` (A данные, B процесс/модель, C фото, D атмосфера), `label` («реальные данные» | «симуляция» | «схема» — по тому, как сделан кадр), `view_type`, `params`, `caption` (≤8 слов, ≥1,5 с на экране), `caption_note` (необязательная мелкая подпись), `plates` (плашки честности: «не в масштабе…», «условные числа», условия применимости), `what` (описание для проверки).

| view_type | Что рисует | params | Закрывает |
| --- | --- | --- | --- |
| `title_card` | крупная фраза (крючок, вывод) | `text`, `sub`, `px` | любой тип; класс D |
| `chips` | карточки с цветным образцом (список терминов, минералов, фаций) | `items:[{label,color}]`, `note` | Р (признаки), перечисления |
| `log_bar` | логарифмическая шкала с выделенным диапазоном из книги | `axis_min`,`axis_max`,`tick`,`min_exp`,`max_exp`,`label`,`tag`,`gloss`,`unit`,`reveal` | В (величины), И |
| `compare` | «слева наблюдение → справа допущение/вывод» (стрелка сигнал → вывод) | `left_title`,`left`,`right_title`,`right` | И, Ф, Н |
| `xy_plot` | график по точкам, строится по точкам по очереди | `xlabel`,`ylabel`,`points:[[x,y]…]`или `"model_R"`,`xmax`,`ymax`,`note` | Ф, И |
| `conclusion` | цепочка «из → в», «не X», плашка условия | `from`,`to`,`not`,`condition`,`condition_note` | Ф, И, Н |
| `rock_grid` | срез породы на сетке; ток по порам, счётчик R (нужна модель `resistor_grid_2d`) | `mode`(idle/current/swap/saturated/exception),`show_R`,`rho_index`,`options`,`timer`,`mixed` | М (проводимость, фильтрация-аналоги) |
| `ion_surface` | схема ионов у твёрдой поверхности | `solid_label`,`water_label`,`note` | М |
| `plan_bend` | вид сверху: излучина расширяется; размыв вогнутого (внешнего) берега, отложение на внутреннем | `migrate_s`,`progress`,`migrate`,`labels`,`erode_label`,`deposit_label` | М, В (латеральная миграция) |
| `column` | стратиграфическая колонка, слои СНИЗУ ВВЕРХ (первый в списке — нижний), стрелка тренда | `layers:[{label,color,h,pattern}]` (`pattern`: gravel/crossbed/plane/silt/пусто), `axis_label`,`step`,`note` | В, Р (последовательность признаков) |
| `flood_section` | разрез поймы: уровень воды поднимается и спадает, осадок оседает из суспензии | `period`,`static`,`level`,`deposit`,`label_flood` | М, В |
| `split` | составной кадр: синхронные виды рядом (слева/справа или сверху/снизу) | `panels:[{title,view_type,params}]`, `direction`("vertical") | любой: «синхронные виды» разбора 16:9 |

Класс C (фото керна, шлифа, обнажения) не реализован: фото берутся только реальные (рисунок из книги с указанием страницы и рисунка), шаблона `photo` пока нет; если узлу нужно фото, пиши в `ask-mentor.md` «нужен новый шаблон: photo» и обходись схемой с честной меткой.
Если для нужного смысла шаблона нет: не выдумывай `view_type`. Выбери ближайший (`title_card`, `chips`, `compare`) и запиши в `ask-mentor.md` «нужен новый шаблон: …».
