Задача: враждебная проверка паспорта ролика. Подстановки выше: CHAPTER, NODE, VIDEO_ID, PASSPORT_DIR, ROUND (номер круга), REPORT (файл отчёта).
Проверь по скану PDF (chapters/$CHAPTER/*.pdf, pdftoppm -r 150, прочитай глазами) страницы узла:
1. Каждое утверждение голоса (voiceover.txt), подписей (scene_spec.frames[].caption/params/plates) и числа против книги; «голос не говорит больше источника»; причины и «почему», которых нет в книге, — замечание.
2. Заблуждения domain-pack/DOMAIN/misconceptions.json (tier core = критическая ошибка) и physics_checklist.json; нарушенная причинность, закреплённое заблуждение, неверная физика, условное выдано за факт книги.
3. Пауза на предсказание (≥2,0 с, ответа до её конца нет), хронометраж формата (short 40–75 с, long 90–180 с итого), первый кадр-крючок, финальный вопрос на перенос, метки происхождения, плашки «не в масштабе», подписи ≤8 слов, шаблоны только из tools/video/views.md.
4. Согласованность passport.json, scene_spec.json, voiceover.txt (число фраз, id, claim).
Формат отчёта (REPORT): как в passports/lat-s01-13-short/verify-r2.md: для каждого замечания id (V-$VIDEO_ID-R<ROUND>-NNN), где, тяжесть (критическая / существенная / незначительная), категория, проблема, источник (цитата со страницей), исправление, уверенность; в начале «Проверено: …; Не проверено: …»; обязательная строка `Итого: критических N, существенных M, незначительных K.` Ничего кроме REPORT не меняй.
