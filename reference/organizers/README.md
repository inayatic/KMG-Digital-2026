# Материалы организаторов (получены в ходе хакатона)
Это материалы организаторов, а не наши. Приватный репозиторий, публиковать нельзя.
- `02_модуль_проверки/` — формат внешнего пакета и скорер (`score_review.py`), контрольный пакет по главе Вендельштейна с ключом (`key.json`: НЕ открывать до прогона нашего модуля).
- `03_стайлгайд/` — легенда и `styleguide.json` (цвета пород, флюидов, кривых, метки происхождения).
- `04_доменные_заготовки/` — стартовые `misconceptions.json` (id misc.*), `physics_checklist.json` (pc.*), ударения, портреты зрителя.
- `05_шаблоны/` — `manual_edits.csv`, `metrics.csv`, `MANIFEST_template.md`, структура доменного пакета.
- `06_подача_и_референсы/` — расшифровка типов трудности (М, В, И, Ф, П, Пр, Н, Р) и форматы подачи; разборы 4 роликов.
