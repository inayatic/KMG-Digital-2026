## Запуск
Одна команда на главу: `make course CHAPTER=<имя>` (стадии: clean_ref → make_units → nodes → verify → org → course). Метрики токенов и денег пишет `tools/stage.py` в `metrics/metrics.csv`; ручные правки: `tools/edit-log` → `metrics/manual_edits.csv`.

## Модуль проверки
`make review PACKAGE=<package.json> [OUT=<ответ.json>]` → `build/review/<package_id>/ответ.json` (+ `notes.md`, `merge-log.md`); агент verifier, 6 срезов параллельно. Контрольный пакет: 19/21 полностью, 95 % по весу, 0 ложных, 1 мин, $1,97 (`metrics/verifier.md`).

## Доменные пакеты
`domain-pack/geology/` (по умолчанию), `domain-pack/filtration/` (сдвиг домена, `docs/shift.md`). Выбор: `make course CHAPTER=<гл> DOMAIN=<домен>`.
