# Плейбук: как собрать конвейер под новый домен

Движок не должен знать предметной области: всё предметное лежит в доменном пакете `domain-pack/<домен>/` (структура: reference/organizers/05_шаблоны/domain_pack_template.md). Первый домен: `domain-pack/geology/`.

## Шаги для нового домена (записывайте время каждого)
1. Положить главу в `chapters/<имя>/` (md с маркерами страниц и PDF). `make course CHAPTER=<имя>` уже даёт слой и курс без доменного пакета: слой строится только по книге.
2. Собрать доменный пакет агентом: промпт `tools/prompts/domain_pack.md` (глоссарий RU/EN, заблуждения `misc.*`, чек-лист физики `pc.*`, ИТ-аналогии, стайлгайд, произношение и ударения, лист опечаток). Источники только книга; всё вне книги помечается «вне книги, проверить».
3. Переписать под домен: список запрещённых заблуждений (то, что нельзя закреплять в курсе и роликах), чек-лист корректности, словарь ударений.
4. Шаблоны сцен для роликов по типам трудности (М, В, И, Ф, П, Пр, Н, Р): `domain-pack/<домен>/templates/` и `tools/video/` (docs/video.md); для каждого типа записать «шаблон закрывает / нужен новый».
5. Прогнать `make course CHAPTER=<имя>`, затем `make check CHAPTER=<имя>`, записать время и стоимость (metrics/summary.md).

## Промпты стадий (назначение)
| Файл | Стадия | Назначение |
|---|---|---|
| extract.md | nodes | узлы раздела: утверждения, цитаты, страницы, связи, покрытие единиц |
| fix_cov.md | nodes (ремонт) | исправление пробелов покрытия и целостности по отчёту `check_cov` |
| verify.md | verify | поиск ошибок смысла: переворот знака, потеря условия, сверхобобщение, физика |
| fix.md, fix_r2.md, fix_r4.md, reverify.md, resolve.md | verify (дополнительные круги) | правки по замечаниям, повторная проверка, разбор спорного (вручную) |
| enrich.md | org | тип трудности по определениям организаторов, термины, оценки видеоёмкости, формат |
| course_tasks2.md (course_tasks.md — старый тип) | course | задания на применение правила к новой ситуации; проверка по утверждениям слоя |
| review_tasks.md | проверка курса (по требованию) | проверка заданий агентом `verifier` |
| review_ctrl.md | модуль проверки | проверка внешнего пакета закладок |
| domain_pack.md | домен | сборка доменного пакета |
| course.md | course (устаревший общий) | заготовка |

Агенты: `.claude/agents/` (layer-extractor, verifier, geo-expert, course-builder, scenario-writer, novice-tester). Замена модели: переменная `LLM_MODEL`. Замена агентов на другой стек (не Claude Code): заменить функцию `llm()` в `tools/stage.py`: она принимает агента и промпт и возвращает токены и стоимость.

## Что известно как зашитое под геологию и не переносится само
Типы трудности и форматы подачи (организаторские, для геологии), стайлгайд цветов (породы, флюиды), словарь ударений, список заблуждений, чек-лист физики. Код стадий предметной области не содержит, но `tools/build_course.py` имеет образцы иллюстраций под Латышову (используются только при наличии `tools/course_config/<имя>.json`).
