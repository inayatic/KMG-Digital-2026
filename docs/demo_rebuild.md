# Демонстрация пересборки на защите (1–2 минуты)

**Что показать.** Учебный слой — единственный источник для курса. Меняем одно число в слое, собираем курс за полсекунды без модели, и на странице курса это число меняется.

**Проверено 26.11.2026 на `barenblatt_gl1`, раздел s03, шаг «4. Закон Дарси из анализа размерностей; проницаемость».** Год 1856 заменили на 1857. Сборка заняла **0,46 с**. На странице появилось 1857, а зелёная галочка «проверено» у этого предложения пропала. Потом слой вернули, и курс стал прежним, побайтно, `git status` чистый. Скриншоты: `docs/demo/rebuild-before.png` и `docs/demo/rebuild-after.png`.

## Как это устроено
```
build/<глава>/nodes.json     ← учебный слой: узлы → утверждения (text, page, quote)
        │  python3 -I tools/build_course_all.py <глава>   (без LLM, < 1 с)
        ▼
out/<глава>/<раздел>/index.html   ← страницы курса (одна на раздел) + out/<глава>/index.html (оглавление)
```
- Текст шагов, «Конспект» и «Карточки» берутся из поля `"text"` утверждений в `nodes.json`.
- Блок «Источник» и галочка ✓ берутся из полей `"quote"` и `"page"`. При сборке цитата и все числа из `text` заново ищутся на странице книги (`tools/build_course.py`, функция `verify`). Если числа на странице нет, галочка ✓ не ставится.
- Задания (`build/<глава>/course/tasks2-*.json`) при этом не меняются: их написала модель раньше. Если число стоит в задании, правьте и задание или выберите другое число.

## На защите
**Шаг 1. Правим одно число в слое.** Меняется только поле `text` одного утверждения: цитата из книги остаётся прежней.
```bash
python3 -I - <<'E'
import json
f = "build/barenblatt_gl1/nodes.json"          # глава
NODE, CLAIM = "bar.s03.04-darcy-dimensional", "s03.04.c5"   # узел и утверждение
OLD, NEW = "1856", "1857"                       # было → стало
ns = json.load(open(f))
c = next(c for n in ns if n["id"] == NODE for c in n["claims"] if c["id"] == CLAIM)
assert OLD in c["text"], c["text"]
c["text"] = c["text"].replace(OLD, NEW)
json.dump(ns, open(f, "w"), ensure_ascii=False, indent=1)
print("было:", OLD, "→ стало:", c["text"])
E
```
Можно править и руками в редакторе: откройте `build/barenblatt_gl1/nodes.json`, найдите `экспериментально в 1856` и поменяйте число в строке `"text"`. В строке `"quote"` ниже число не трогайте. Покажите изменение:
```bash
git diff --stat build/barenblatt_gl1/nodes.json
```

**Шаг 2. Собираем курс.**
```bash

```
Ожидаемый вывод: `sections=4 nodes=33 tasks=98 warnings=0 …`, `real 0m0,5s`.

**Шаг 3. Обновляем страницу в браузере (F5).** В шаге 4 раздела s03 вместо «…экспериментально в 1856 г. ✓» стоит «…экспериментально в 1857 г.» без галочки. Если нажать на предложение, откроется «Источник» с цитатой книги «в 1856 г.». Так видно, что курс собирается из слоя, а каждая правка заново проверяется по книге.

## Чего не делать
- **Не запускать `make course` после правки.** Make сравнивает время файлов: `nodes.json` станет новее `verify.md`, и make заново запустит проверку и сборку моделью. Это минуты, деньги, нужен ключ API и интернет. Для показа нужна только `tools/build_course_all.py`.
- **Не править `build/<глава>/org/layer.json`.** Это слой в формате организаторов для сдачи, страницы курса берутся из `nodes.json`. Из `layer.json` в курс попадает только запасной словарь.
- **Не менять число и в `quote`.** Курс соберётся, но цитата перестанет находиться на странице книги (статус `notfound`). Галочка тоже пропадёт, но в «Источнике» будет уже неверная цитата, а для показа «слой → курс и проверка по книге» нагляднее, когда цитата остаётся книжной.
- **Не коммитить изменённый слой.** Верните его шагом 4.

## Если что-то пошло не так
| Что видно | Причина | Что сделать |
|---|---|---|
| Страница не поменялась | браузер показал кэш | Ctrl+F5 или закрыть и открыть файл заново |
| `AssertionError` в шаге 1 | число уже изменено или другой id | `git checkout build/<глава>/nodes.json` и повторить |
| `json.decoder.JSONDecodeError` при сборке | при ручной правке сломана кавычка или запятая | `git checkout build/<глава>/nodes.json` и повторить |
| сборка завершилась с кодом 1 и строками `WARN` | на этой главе были предупреждения и до правки (не из-за демонстрации) | страницы всё равно записаны; обновите браузер |
| нет `out/<глава>/` | курс этой главы ещё не собирался | `python3 -I tools/build_course_all.py <глава>` (нужны `build/<глава>/nodes.json`, `units.json`, `sections.json`) |
