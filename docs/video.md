# Видеоконвейер (роль B)

Узел слоя → паспорт → сценарий → верификатор → озвучка → кадры → mp4 → проверки. Одна команда:

```bash
make video CHAPTER=<глава> NODE=<id узла> [FORMAT=short|long]    # short: 9:16, 40–75 с; long: 16:9, 90–180 с
```

`FORCE=1` пересчитывает все стадии; иначе стадии с готовым результатом пропускаются (сценарий, отчёт верификатора, озвучка, mp4 сравниваются по времени изменения с входами). `JOBS` — число окон браузера при рендере (по умолчанию 6).
`video_id` = `<id узла с «.» → «-»>-<формат>`; паспорт — `passports/<video_id>/`, результаты — `out/video/<video_id>/`.

## Стадии

| № | Стадия | Что делает | Где |
|---|---|---|---|
| 1 | scenario | `claude -p --agent scenario-writer`, промпт `tools/video/prompts/scenario.md`: читает узел слоя, сверяет цитаты по скану PDF, пишет `voiceover.txt`, `scene_spec.json`, `passport.json`, `script.md`, `sources.md`, `ask-mentor.md` | `tools/video/pipeline.py` |
| 2 | verify | `claude -p --agent verifier`, `verify_video.md`; до 3 кругов: при критических или существенных замечаниях `scenario-writer` исправляет по отчёту (`fix_video.md`). Без «0 критических и 0 существенных» рендер не запускается | `passports/<id>/verify-v*.md` |
| 3 | tts | `tools/tts_eleven.py`: ElevenLabs (модель `eleven_multilingual_v2`, голос Alice), фразы между паузами одним запросом, пауза вставляется тишиной, распознавание Scribe даёт слова с временем (`words.json`, `lines.json`) и WER. Скорость 1,0; если дольше предела формата, повтор со скоростью до 1,2 | `out/video/<id>/audio/` |
| 4 | render | `tools/video/render.py`: время кадров из спецификации пересчитывается по фактическим началам фраз озвучки; `scene.js` рисует кадр как чистую функцию времени (Canvas), Playwright делает снимок каждого кадра (30 к/с), ffmpeg собирает mp4; звук нормируется до −16 LUFS (loudnorm, два прохода) | `out/video/<id>/<id>.mp4`, `timeline.json` |
| 5 | check | `tools/video/check_track.py` по готовому файлу: громкость (ebur128), длительность, распознавание дорожки ГОТОВОГО mp4 (WER ≤ 10 %), рассинхрон слов субтитров и дорожки (≤ 0,5 с) | `out/video/<id>/checks.json` |
| 6 | passport | `tools/video/update_passport.py`: фактические времена, `audio_check`, путь к mp4; строка `video` в `metrics/metrics.csv` (`video_seconds`, токены, деньги) | `passport.json` |

Кадры генерируются только кодом: Canvas по данным модели или функции времени, генерации изображений и интерполяции видео нет. Текст, цифры, оси, стрелки, субтитры и метки происхождения («реальные данные» / «симуляция» / «схема») накладываются на монтаже. Каталог шаблонов с параметрами: `tools/video/views.md`.

## Входы и выходы
Вход: `chapters/<гл>/*.pdf` (сканы для сверки), `build/<гл>/org/layer.json` (узел), `domain-pack/geology/*` (заблуждения, физика, словари). Выход: `out/video/<id>/<id>.mp4`, `passports/<id>/` (паспорт по схеме организаторов, сценарий, источники, `ask-mentor.md`, отчёты верификатора), `checks.json`.
Зависимости: python3 + numpy, jsonschema, Pillow (для просмотра превью, не обязателен), node + playwright + Chromium (в контейнере), ffmpeg/ffprobe, `claude` CLI. Ключ ElevenLabs не нужен: заголовок подставляет прокси окружения (хост api.elevenlabs.io); наружу уходит только текст озвучки.

## Что делается руками
- выбор узла и формата (на тесте назначают организаторы);
- прослушивание ролика целиком (ударения, интонация): автоматически не проверяется;
- решения по `ask-mentor.md` (спорная физика, «нужен новый шаблон»);
- при провале верификатора после 3 кругов или сбое проверок: правка сценария и повторный запуск (`make video …`, готовые стадии пропустятся; число кругов верификатора: `ROUNDS=N`, по умолчанию 3).

## Что НЕ проверяется автоматически
Правильность ударений и интонации; «красота» кадров (кадры смотрит человек, превью: `python3 tools/video/render.py <паспорт> <audio> <папка> --preview 5,20,31`); физическая и фактическая верность опирается на верификатор-агента (модель), а не на независимого эксперта; пропорциональность R в модели `resistor_grid_2d` следует из построения (σ пор = 1/ρв), модель иллюстрирует допущение книги, а не проверяет его.

## Покрытие шаблонами сцен по типам трудности
Статус: «есть» — шаблон реализован и использован в ролике; «частично» — ближайший шаблон закрывает часть; «нужен новый» — шаблона нет. Модель состояния — что вычисляется из данных слоя (шаблон не содержит геологии: числа и подписи приходят из `params`).

| Тип | Что нужно показать | Шаблоны (tools/video/scene.js) | Модель состояния | Статус |
| --- | --- | --- | --- | --- |
| М механизм | что куда движется и почему | `rock_grid` (ток по порам; счётчик R), `plan_bend` (смещение излучины), `flood_section` (паводок, осаждение), `ion_surface` | `resistor_grid_2d` (div(σ∇φ)=0, numpy, сетка 64×64); `plan_bend` и `flood_section` — функции времени (кинематика схемы, не расчёт гидравлики) | есть; фильтрация, волна давления, рост рифа: нужен новый (модель + шаблон) |
| В время | порядок событий, гипотеза помечена | `column` (слои снизу вверх, стрелка тренда), `log_bar` | порядок слоёв из слоя; времён в годах нет | частично; шкала этапов с пометкой «гипотеза»: нужен новый |
| И косвенное измерение | сигнал → отклик → свойство; неоднозначность | `compare` (наблюдение → вывод), `xy_plot` (точки из модели), `conclusion` | `xy_plot` берёт точки из модели `resistor_grid_2d` или из `params` | частично; кривая по глубине рядом с разрезом (синхрон прибор–кривая–интерпретация) и «два разреза с похожим откликом»: нужен новый |
| Ф формализм | смысл членов формулы, что меняется | `xy_plot`, `compare`, `conclusion`, `log_bar` | точки из модели или из `params` | частично; разбор членов формулы и ползунок: нужен новый (ползунок живёт в интерактиве) |
| П пространство | объём, сечение, синхронные виды | `split` (план + колонка рядом), `plan_bend`, `flood_section` | схемы без 3D | частично; сечение с перемещаемым разрезом: нужен новый |
| Пр процедура | порядок действий, точки выбора | `chips`, `conclusion`, `title_card` | нет | нужен новый (`flowchart`: шаги, развилки, ручной труд) |
| Н неопределённость | диапазон вместо числа, сценарии | `log_bar` (диапазон), `compare` | нет вычисляемой модели | нужен новый (веер сценариев / диапазон с вероятностями) |
| Р распознавание | признак на фото, шлифе, кривой | `chips` (признаки), `column` (последовательность признаков) | нет | частично; класс C (фото из книги с указанием рисунка и страницы): нужен новый `photo`. Синтетические керн и шлифы запрещены |

## Известные ограничения
- Шаблоны построены на двух узлах (проводимость породы; фации излучины); на другом типе узла сценарист может не найти подходящего шаблона и запишет «нужен новый шаблон» в `ask-mentor.md`, а кадр будет схемой из `chips`, `compare` или `title_card`.
- Класс кадров C (реальные фото) не реализован; истинный масштаб пласта не показан (ролики о механизме на уровне зёрен или схемы).
- Озвучка ElevenLabs недетерминирована: повторный запуск с `--force` даёт другое аудио и другие времена слов.
- Ускорение речи (speed до 1,2) нужно, чтобы уложиться в формат: нативный темп голоса ≈ 105 слов/мин.
