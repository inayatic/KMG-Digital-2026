# Рендер ролика lat-s01-13-short (шортс 9:16)

Файл: `build/video/lat-s01-13-short/lat-s01-13-short.mp4` (H.264 1080×1920, 30 к/с, AAC 192 кбит/с).

## Как собрать заново (детерминированно)
```
python3 tools/tts_eleven.py passports/lat-s01-13-short/voiceover.txt passports/lat-s01-13-short/audio-stress --keep-stress
python3 tools/video/sim_grid.py passports/lat-s01-13-short/scene_spec.json build/video/lat-s01-13-short/sim.json
python3 tools/video/timeline.py passports/lat-s01-13-short passports/lat-s01-13-short/audio-stress build/video/lat-s01-13-short
node tools/video/render.js tools/video/lat-s01-13-short.html build/video/lat-s01-13-short build/video/lat-s01-13-short/lat-s01-13-short.mp4
```
Озвучку (шаг 1) повторять не нужно: mp3 и words.json лежат в `audio-stress/`; повторный вызов TTS даёт другое исполнение.

## Отклонения от спецификации (честно)
- Длительность 81,5 с вместо 70 с: озвучка длиннее плана; кадры растянуты пропорционально по строкам озвучки. Три кадра длиннее 5,5 с (минералы 6,5 с, график 6,9 с, «вода ×2» 6,0 с): внутри них есть движение (появление карточек, точек, смена ρв), но правило «смена кадра 3–5,5 с» нарушено.
- Шрифт Inter вместо Segoe UI (в контейнере его нет).
- R2-003 (формулировка v01 «порода из изоляторов») не исправлена: голос не перегенерировали, уверенность замечания низкая.
- Ударения на слух человек не проверял; «по́ровая» распознаётся как «паровая» — нужно послушать.
- Словари `stress_dictionary.md`, `pronunciation.md` новыми словами не дополнены.
