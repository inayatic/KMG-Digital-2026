Карточки

Какой метод видит какую пористость

Обозначения вида k_п,общ, k_п,из (в тексте OCR так же k_п,мз), k_п,т, k_п,вт: у каждого вида пористости свой метод; это сводная карта параграфа (структура взята из порядка изложения).

Метод сопротивлений даёт открытую межзерновую пористость в терригенных и межзерновых карбонатных породах.✓

Сопротивление воды по методу СП

Уравнение ΔE = -k_СП lg(ρ_ф/ρ_в) содержит два неизвестных (k_СП и ρ_в), поэтому ρ_в определяется двумя подходами.

Для расчёта пористости и нефтегазонасыщения интерпретатору должно быть известно удельное сопротивление пластовой воды; кроме анализов ионного состава для этого используется метод СП.✓

Пористость за контуром залежи

Метод даёт k_п лишь там, где известна неизменённая часть пласта; его область применения ограничена законтурной частью (вывод из недостатка 1).

Определение пористости по сопротивлению коллектора за контуром состоит из операций: сопротивление неизменённой части пласта; сопротивление воды в пластовых условиях; P_п = ρ_кп/ρ_к и k_п по зависимости P_п = f(k_п).✓

Пористость по промытой зоне

Расчёт по промытой зоне: ρ_пп по микроэкранированным зондам; ρ_ф по кривым рис. 3; затем P_п по формуле (67); по P_п находят k_п.✓

Коэффициент остаточного нефте-, газонасыщения принимают равным нулю для водоносных пластов.✓

Параметр q и группы коллекторов

Путь через q применяют, когда информация о коэффициентах П и P_п,по не может быть получена с достаточной достоверностью, но пористость некоторых пластовых пересечений известна по другому методу или по представительному керну.✓

q есть отношение фактического ρ_пп по диаграммам к расчётному P_п ρ_ф и учитывает одновременное влияние поверхностной проводимости и остаточного нефте-, газонасыщения.✓

Пористость по зоне проникновения

Расчёт по зоне проникновения: найти ρ_зп; найти ρ_ф по ρ_р и t; рассчитать P_п по формуле с ρ_вф (смесь фильтрата и пластовой воды); по P_п установить k_п по зависимости, соответствующей типу коллектора.✓

Сопротивление смеси фильтрата и пластовой воды определяется из соотношения 1/ρ_вф = z/ρ_в + (1-z)/ρ_ф, где z - доля остаточной пластовой воды в порах коллектора в зоне проникновения.✓

Трещинная пористость: два раствора

Трещинный карбонатный или терригенный коллектор с плотной непроницаемой матрицей: трещинная пористость определяется разными способами.✓

Способ двух растворов: две диаграммы метода сопротивления, обычно экранированного зонда (БК-3), на растворах с разным сопротивлением фильтрата.✓

Вторичная пористость сложных карбонатов

В сложных карбонатных коллекторах (кавернозно-трещинных с плотной матрицей или кавернозно-трещинно-межзерновых с проницаемой матрицей) рекомендуется расчёт k_п,вт по формуле (72).✓

k_п,общ определяют по нейтронным методам или гамма-гамма методу; k_п,мз - по диаграмме ΔT акустического метода.✓

Кросс-плоты для сложного скелета

Для общей пористости при сложном минеральном составе нужен комплекс методов, показания которых зависят от пористости и литологии (НМ, ГТМ, АМ).✓

В песчано-глинистом разрезе определяются два параметра: пористость и глинистость; в смеси известняк+доломит комплекс позволяет определить пористость и минеральный состав.✓

Пример 56: опорные точки

Проверка по формуле автора: для кварца 2,65 - 0,4(2,65 - 1) = 1,99; для известняка 2,71 - 0,4(2,71 - 1) = 2,026 (в тексте 2,025); для доломита 2,85 - 0,4(2,85 - 1) = 2,11; для глины 2,7 - 0,4(2,7 - 1) = 2,02.

Пример 56 требует координаты опорных точек для кросс-плотов рис. 82 при k_п = 0 и k_п = 0,4 (40 %) для чистых пород: кварц, известняк, доломит, глина сухая, вода пресная.✓

Пористость по СП через глинистость

Метод региональный: зависимость α_СП = f(k_п) не переносится между районами без проверки (вывод из условия связи пористости с глинистым цементом).

Определение пористости методом СП возможно в ряде районов, где пористость связана со степенью заполнения пор глинистым цементом.✓

Как это работает

Разные методы реагируют на разные части порового пространства, поэтому каждый даёт свой вид пористости [модель; у автора только перечень «метод - вид пористости»].

Как делают сейчас

Книга описывает аналоговый комплекс (НМ, ГГМ, АМ, ЯМР); современность не оценивалась.

Цифры и условия

Перед расчётом выбрать, какой вид пористости нужен, и подобрать метод/комплекс из списка автора.

Оговорки

Для сложных карбонатов определяются k_п,общ и компоненты; условие: комплекс НМ, ГГМ, АМ. ЯМР не годится для низкопористых трещинных коллекторов.

Частая ошибка

[гипотеза, модель] Одна «пористость по каротажу» одинакова для всех методов; глава показывает, что виды пористости различны и методозависимы.

Что это значит для данных

Значение k_п без указания вида (общая, межзерновая, трещинная, эффективная) и метода сравнивать нельзя (вывод из перечня автора).

Аналогия с границей применимости

Разные сенсоры в мониторинге видят разные метрики одного сервиса (CPU, latency, ошибки).

Где аналогия ломается. Виды пористости связаны физически (общая = сумма компонент), а метрики сервиса независимы.

Чего в книге нет

  • Что такое эффективная пористость и как её даёт ЯМР: в главе только упомянуто.

Суть

Для расчёта пористости и нефтегазонасыщения интерпретатору должно быть известно удельное сопротивление пластовой воды; кроме анализов ионного состава для этого используется метод СП.✓ [PDF-стр. 115]

Уравнение ΔE = -k_СП lg(ρ_ф/ρ_в) содержит два неизвестных (k_СП и ρ_в), поэтому ρ_в определяется двумя подходами. [PDF-стр. 115]

Подход 1: нужна регистрация диаграмм СП в скважине с двумя растворами с разными сопротивлениями фильтрата; получают два уравнения (70).✓ [PDF-стр. 115]

Как это работает

ΔE связана с lg отношения сопротивлений фильтрата и пластовой воды; два замера при разных ρ_ф исключают неизвестную k_СП.

Как делают сейчас

Графический метод на бланке полулогарифмической бумаги и номограммы описывают ручную технику; современные способы в главе не рассмотрены.

Цифры и условия

Либо два раствора и прямая на полулогарифмической бумаге, либо опорная k_СПmax с поправкой на температуру и номограмма.

Оговорки

Второй путь верен приближённо: при k_СП не равной k_СПmax нужен b_c или номограмма-поправка. Обозначения ρ_п/ρ_в в OCR перепутаны (ρ_п может стоять вместо ρ_в); термины α_СП, k_СП, уравнение (24) объясняются в других параграфах.

Формулы главы

Уравнения (70): ΔE' = −k_СП · lg(ρ_ф' / ρ_в) и ΔE'' = −k_СП · lg(ρ_ф'' / ρ_в). Здесь ΔE' и ΔE'' — амплитуды СП при двух растворах, ρ_ф' и ρ_ф'' — сопротивления фильтрата этих растворов, ρ_в — удельное сопротивление пластовой воды (искомое), k_СП — коэффициент метода СП.✓ [PDF-стр. 115]

Расшифровка символов и единиц: в утверждениях шага (блок «Источник»).

Частая ошибка

[гипотеза] ρ_в всегда берётся из анализа воды; автор называет СП альтернативой.

Что это значит для данных

Точность ρ_в зависит от подхода: для подхода 2 допущена опорная k_СПmax (допущение автора, «с большей вероятностью»).

Где аналогия ломается. Здесь прямая строится в полулогарифмическом масштабе; в общем случае линейная калибровка не логарифмическая.

Суть

Путь через q применяют, когда информация о коэффициентах П и P_п,по не может быть получена с достаточной достоверностью, но пористость некоторых пластовых пересечений известна по другому методу или по представительному керну.✓ [PDF-стр. 113]

q есть отношение фактического ρ_пп по диаграммам к расчётному P_п ρ_ф и учитывает одновременное влияние поверхностной проводимости и остаточного нефте-, газонасыщения.✓ [PDF-стр. 114]

Две неизвестных (q и k_п) определяют способом последовательных приближений: по средней пористости находят q, затем P_п и k_п; повторяют, пока последнее значение k_п практически не совпадает с предыдущим.✓ [PDF-стр. 114]

Как это работает

q = ρ_пп/(П ρ_ф) = P_п,по · П: объединяет поверхностную проводимость и остаточное насыщение; по ней строится зависимость q = f(k_п).

Цифры и условия

Опорные пласты с известной k_п, зависимость q(k_п), затем итерации k_п - q - P_п.

Оговорки

Требует опорных пластов с известной пористостью; не рекомендуется для частично гидрофобных коллекторов с вязкой нефтью и твёрдыми битумами. В OCR формулы q/ρ_пп/ρ_пп.расч обозначены неоднозначно.

Частая ошибка

[гипотеза] q — свойство отдельного пласта, а не района; автор строит зависимости q = f(k_п) для районов.

Что это значит для данных

Класс коллектора по q (глинистость и пористость) получается как побочный продукт расчёта (по автору).

Аналогия с границей применимости

Итерационная оптимизация до сходимости (fixed-point iteration).

Где аналогия ломается. Критерий остановки у автора качественный («практически совпадает»), без числового порога.

Трещинный карбонатный или терригенный коллектор с плотной непроницаемой матрицей: трещинная пористость определяется разными способами.✓ [PDF-стр. 114]

Как это работает

Трещинная пористость определяется по изменению сопротивления зоны проникновения при смене раствора (формула 68) или по сопротивлению и методу пористости при минерализованном растворе (69).

Как делают сейчас

Цифры и условия

Две диаграммы БК-3 с разными ρ_ф после промывки с противодавлением, либо БК-3 и один метод пористости.

Оговорки

Формулы главы

Формула (68), трещинная пористость по способу двух растворов: k_п.т = ρ_ф1 · ρ_ф2 · (ρ_зп2 − ρ_зп1) / [A · ρ_зп1 · ρ_зп2 · (ρ_ф2 − ρ_ф1)]. Здесь ρ_ф1, ρ_ф2 — сопротивления фильтрата двух растворов, ρ_зп1, ρ_зп2 — удельные сопротивления зоны проникновения трещинного коллектора по первому и второму замерам, A — значение для принятой системы трещин по табл. 2.✓ [PDF-стр. 115]

Формула (69), трещинная пористость при вскрытии на минерализованном растворе: k_п.т = (−1/A) · (ρ_в / ρ_зп.т − 1 / P_п.бл). Здесь ρ_в — сопротивление пластовой воды, ρ_зп.т — сопротивление зоны проникновения трещинного коллектора, A — коэффициент для системы трещин, P_п.бл — параметр пористости блоков трещинного коллектора, который можно принять равным k_п.бл^(−2) при k_п.бл = k_п.мз.✓ [PDF-стр. 115]

Оговорки

Акустика видит каверны, размер которых близок к длине продольной волны (15-20 см) или больше; мелкие каверны (до 1-2 см) ведут к занижению вторичной пористости. В OCR обозначение k_п,мз в формуле (72) виде k_п,ms.

Формулы главы

Формула (72): k_п.вт = (k_п.общ − k_п.мз) / (1 − k_п.мз), где k_п.общ определяют по диаграммам нейтронных методов или гамма-гамма метода, а k_п.мз — по диаграмме ΔT акустического метода; k_п.вт = k_п.к + k_п.т по тексту автора.✓ [PDF-стр. 115]
